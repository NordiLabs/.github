# NordiLabs

> Native software for Sailfish OS — and the Android apps you still need, running like they belong there.

NordiLabs builds apps and tooling for **Sailfish OS**: native Silica apps, faster developer workflows, and an ongoing effort to run **unmodified Android apps as true Sailfish citizens** — their own windows, cards, notifications and audio.

## Projects

| Project | What it is | Status |
|---|---|---|
| [build-sailfish-apps-on-apple-silicon](https://github.com/NordiLabs/build-sailfish-apps-on-apple-silicon) | Build Sailfish OS apps natively on Apple Silicon Macs — much faster than the emulated SDK | Available |
| SailTube | Native YouTube client for Sailfish OS | Coming soon |
| SailTune | Native music player for Sailfish OS | Coming soon |
| Android on Sailfish | Android 16 apps integrated as native Sailfish apps, layer by layer | In development |
